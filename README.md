# Lumatrix City Studio

**도시를 만들고, 시설의 연결과 운영 상태를 3D로 살펴보는 도시 편집 도구입니다.**

## 개요

Lumatrix City Studio는 건물과 시설, 부지, 도로, 교량을 배치하고 지형과 수면을 편집해 도시 장면을 구성하는 3D 편집기입니다. 웹과 데스크톱에서 사용할 수 있으며, 도시의 모습과 시설 정보를 한 화면에서 확인할 수 있습니다.

## 목적

도시 구상과 시설 배치 아이디어를 눈에 보이는 장면으로 표현하고, 시설 간 연결 관계와 공급 상태를 쉽게 이해할 수 있도록 돕습니다. 도시 구성안 비교, 인프라 연결 설명, 운영 시나리오 시연에 활용할 수 있습니다.

## 주요 기능과 장점

| 기능 | 활용과 장점 |
| --- | --- |
| **3D 도시 구성** | 시설·부지·도로·교량을 직접 배치해 공간의 구조와 배치 관계를 확인할 수 있습니다. |
| **지형과 환경 편집** | 지형 높이, 지면, 수면, 낮·밤 조명을 조절해 다양한 도시 분위기를 표현할 수 있습니다. |
| **시설 연결 시각화** | 전력·수도·일반 연결선을 색상과 흐름 애니메이션으로 표시해 시설 간 관계를 쉽게 설명할 수 있습니다. |
| **시설 정보와 운영 확인** | 시설 이름·설비 코드·운전 상태를 관리하고, 전력 수급과 수도 연결 상태, 고장·복구에 따른 영향을 살펴볼 수 있습니다. |
| **효율적인 반복 편집** | 복제, 다중 선택, 일괄 이동, 잠금, 실행 취소·다시 실행으로 배치안을 빠르게 수정할 수 있습니다. |
| **도시 현황 탐색** | 시설 목록, 구역 관리, 정보 레이어, 미니맵과 진단 기능으로 필요한 위치와 상태를 찾을 수 있습니다. |
| **저장과 재사용** | 도시 데이터를 JSON 파일로 저장하고 불러와 작업을 이어가거나 다른 구성안에 활용할 수 있습니다. |
| **내장 한국어 매뉴얼** | 사용법, 단축키, 프리셋 설명과 튜토리얼을 편집 화면에서 확인할 수 있습니다. |

## 활용 예시

- 도시와 단지의 시설 배치안을 만들고 비교하기
- 전력·수도 시설의 연결 구조를 시각적으로 설명하기
- 시설이나 연결선의 고장·복구에 따른 공급 상태 변화를 시연하기
- 지형과 조명을 활용해 도시 콘셉트와 장면을 표현하기
