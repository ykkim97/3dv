# 순차 기능 개발 기록

선행 편의 기능: 게임 스타일 기본·버튼·배치 포인터, F키로 선택 시설/부지의 전체 외곽에 맞추는 근접 포커스 구현. 다중 선택과 화면 패널 여백을 반영하고 현재 시점 방향을 유지한다. 다음은 아래 8단계부터 이어간다.

사용자 요청에 따라 아래 순서를 유지한다. 1~7단계를 구현했으며 다음 기능 개발은 8단계부터 이어간다. 이 기록은 자동 작업 실행을 의미하지 않는다.

1. **완료: 시설 속성 관리** — 이름, 설비 번호, 운전 상태, 출력·수요·용량; JSON 저장, 중복 검사, 복제, 실행 취소.
2. **완료: 연결망 기반 공급 계산** — 전력·수도 방향과 운전 상태에 따른 경로 판정, 차단 원인 및 경로 표시. 전력은 발전 출력·중계 용량·소비 수요를 모두 입력한 망에서 용량 제한과 우회 경로를 반영한 배분·부족량 계산. 미입력과 0을 구분하고 독립된 망별로 계산한다. 전력 부족·수치 미설정 상태 아이콘을 제공한다. 기존 파일은 반경 방식 유지. 수도는 연결 판정만 제공하며 ESS 충방전·전압·손실 모델은 포함하지 않는다.
3. **완료: 고장·복구 시나리오** — 시설/연결 차단과 복구, 적용 전 대비 소비시설 영향 비교. 실제 도시 상태·저장·실행 취소에 반영하며 대상 필드만 원래 상태로 복구한다. 복구 기록은 실행 중에만 유지된다.
4. **완료: 운영 대시보드** — 전력 출력·수요·공급·부족량과 전력/수도 연결 상태, 미입력 경고를 집계하고 해당 시설로 이동. 부분 집계를 명시하며 공정한 배분이나 실제 계통 해석으로 표현하지 않는다.
5. **완료: 연결선 경유점 편집** — 지도 클릭·좌표 입력·이동·순서 변경·삭제·자동 경로 복귀. 최대 32점, 시설 이동 시 끝점 추종, JSON·실행 취소 지원.
6. **완료: 성능 모니터·품질 설정** — FPS·CPU 처리 시간·활성 메시·드로 콜, 해상도·그림자·30/60 FPS·움직임 설정. 불필요한 포인터 피킹 제거, 공급 계산 공유, 연결선 모양 캐시 재사용. 2,000선 NullEngine 부하 검증은 구조·CPU 검증이며 실제 GPU FPS 검증은 별도 필요.
7. **완료: 자동 저장·복구·프로젝트 목록** — IndexedDB 트랜잭션, 1.8초 편집 대기/최대 10초 저장 시작, 직렬 쓰기·최신 변경 합치기, 10개 프로젝트·최근 3개 저장본, 시작 시 복구 선택과 오류·재시도 표시. 강제 종료 시 마지막 완료본까지만 보장. 브라우저 저장소·UI 실기 검증은 별도 필요.
8. 복합 시설 프리셋 — 발전단지, 변전소, 산업단지 등을 묶어 배치.
9. 발표 모드·카메라 투어 — 편집 UI 숨김과 저장 시점 순회.
10. 외부 데이터 연결 — CSV/JSON부터 시작하고 이후 실시간 데이터 연결.

공통 원칙: 시설 수가 늘어도 프레임 부하를 줄이도록 변경 시 계산, 렌더링 캐시, 필요 시 Worker를 사용한다. 실제 FPS는 측정 없이 개선 수치를 주장하지 않는다. 각 단계는 기존 도시 JSON과 실행 취소를 검증한다.

## 프리셋 확장 진행 상황

- 완료: 확장 1~5단계의 13종 프리셋 — 물류센터·일반 창고·냉동 창고, 소형 제조공장·조립공장, 일반 주차장·주차타워·버스 차고지, 재활용 선별장·자원회수시설, 도서관·체육관·주민센터. 교통·주차와 환경·자원 카테고리 및 세부 분류를 추가한다. 기존 공급·소방 판정과 전력 수요 계산을 사용하며, 화물·재고·차량·폐기물·문화 서비스 시뮬레이션은 포함하지 않는다.

- 완료: 시설 라이브러리 세부 분류, 이름·용도 검색, 분류별 개수 표시. 상업·업무와 산업시설을 분리하되 기존 시설 ID와 저장 데이터의 내부 카테고리는 유지한다.
- 완료: 급속 충전소, 완속 충전기, 태양광 주차장. 충전기는 전력 소비시설이며 수도 공급 대상이나 중계시설이 아니다. 태양광 주차장은 입력한 출력으로 발전한다. 정적 모델은 재질별 병합과 인스턴스 공유를 사용한다.
- 검증: 도시 테스트 120개, 린트, 프로덕션 빌드 통과. 실제 화면의 배치와 GPU FPS는 별도 실기 확인이 필요하다.
- 다음 확장은 별도 요청에 따라 진행하며, 기존 복합 시설 프리셋·발표 모드·외부 데이터 연결 계획도 유지한다.

## 매뉴얼과 향후 JavaScript API 안내

- 매뉴얼: `src/features/city/manual/`. 실제 프리셋 카탈로그와 흐름 효과 목록을 사용한다.
- 향후 별도 요청: 비개발자도 쉽게 사용할 JavaScript 편의 API. 현재 도시 편집기에는 공개 편의 API가 없으므로, 매뉴얼에서는 준비 중으로 표시하고 가상의 함수를 사용 가능한 것으로 소개하지 않는다.
- API를 구현하면 문법, 입력값, 반환값, 오류, 실행 취소, 복사 가능한 예제를 매뉴얼에 함께 추가한다.
