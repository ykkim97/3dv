# Smart Grid · 연결된 도시 탐험

사용자가 제공한 `Smart Grid Main Page.json`을 메인으로 삼은 4페이지 데모입니다.
원본 파일은 수정하지 않았으며, 프로젝트의 메인 씬에서도 기존 시설 726개·도로 73개·연결선 208개·지형을 보존했습니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `Smart_Grid_Connected_Demo.project.json` | 메인 + 3개 서브 씬 + 이동 포인트 9개 + 각 페이지 시작 카메라 |
| `00_Smart_Grid_Main.city.json` | 기존 메인 도시의 독립 씬 |
| `01_Renewable_Energy_Campus.city.json` | 풍력·태양광·ESS·전기차 충전이 연결된 재생에너지 캠퍼스 |
| `02_Power_Control_Campus.city.json` | 원자력·예비 발전소·송전탑·관제센터·스마트 공장으로 구성한 발전·관제 단지 |
| `03_River_Water_Campus.city.json` | 취수·정수·배수·급수·하수처리 시설과 강변 산책로·교량을 갖춘 물순환 센터 |
| `validation-report.json` | 페이지별 개수, 포인트 위치, 공급 경로 검사 결과, 원본 SHA-256 |
| `build-demo.mjs` | 같은 원본에서 데모 JSON을 재생성하는 스크립트 |

**페이지 이동 시연에는 `.project.json`을 불러오세요.** 개별 `.city.json`은 도시만 단독으로 열거나 재사용하기 위한 파일입니다. 외부 페이지 참조 없이 불러올 수 있도록 개별 도시에는 이동 포인트가 들어 있지 않습니다. 연결 프로젝트에는 모든 이동 포인트가 포함됩니다.

## 시연 순서

1. 프로그램 상단 **페이지 → JSON 불러오기**에서 `Smart_Grid_Connected_Demo.project.json`을 선택합니다. 일반 도시 불러오기 대신 페이지 메뉴를 사용하세요.
2. 로딩이 끝나면 메인 도시가 열립니다. **포인트 편집** 버튼을 눌러 **이동 모드**로 바꿉니다. 왼쪽의 선택 도구를 사용하세요.
3. 아래 시설 위의 민트색 포인트에 마우스를 올리면 목적지 이름이 나타납니다. 포인트를 클릭하면 서브 씬으로 이동합니다.
4. 서브 씬에서는 방문센터·홍보관·물문화센터 위의 **메인 스마트그리드 도시로 돌아가기** 포인트를 클릭합니다. 상단 **← 이전**으로도 방문 직전 시점에 돌아갈 수 있습니다.
5. 각 서브 씬 운영센터 위에는 다음 서브 씬으로 가는 포인트도 있습니다. 재생에너지 → 발전·관제 → 물순환 → 재생에너지 순으로 둘러볼 수 있습니다.
6. **페이지** 메뉴에서는 4개 씬을 직접 열 수 있습니다. 처음에는 기본 카드 그림이 보이며, 씬을 방문한 뒤 페이지 메뉴를 열거나 다른 씬으로 이동하면 실제 화면 썸네일이 저장됩니다.

## 메인 씬의 이동 포인트 위치

| 목적지 | 부착 시설 | 지도 좌표 X / Z | 찾기 쉬운 저장 시점 |
| --- | --- | --- | --- |
| 재생에너지 캠퍼스 | 북서쪽 풍력 발전기 | -184 / 176 | 풍력 · 태양광 발전단지 |
| 발전·관제 단지 | 남서쪽 원자력 발전소 | -204 / -198 | 원자력 발전 · 기저전원 |
| 강변 물순환 센터 | 남서쪽 정수장 | -122 / -148 | 전체 전경에서 정수장 쪽으로 확대 |

포인트는 건물에 부착되어 건물 이동·회전을 따라갑니다. 건물을 선택한 뒤 **F**로 확대하면 포인트를 찾기 쉽습니다. 이동 모드가 아닌 포인트 편집 모드에서는 클릭 시 설정 창이 열립니다.

## 서브 씬의 컨셉

- **재생에너지 캠퍼스:** 오후 햇살, 서쪽 언덕과 동쪽 물가, 풍력 6기·태양광 9개 어레이·ESS 3기, 방문센터와 충전 대기 정원. 전력은 노란 연결선, 급수는 파란 연결선으로 구분합니다.
- **발전·관제 단지:** 해질녘 조명, 큰 원자력 발전소와 소형 예비 발전소, 변전·송전 구역, ESS, 관제센터·소방서·제조동. 발전 단지와 산업 수요 구역을 별도 부지로 나눴습니다.
- **강변 물순환 센터:** 오전의 밝은 강변, 양쪽 수처리 캠퍼스, 도로 교량 2개와 중앙 보행교, 전망 카페와 생태정원. 하수 이송 설명용 일반 연결은 보라색으로 구분하며 상수도 공급 경로와 분리했습니다.

서브 씬은 모두 240m 지도이며 시설·조경·소품을 합쳐 각각 96개 / 84개 / 74개입니다. 다른 페이지를 동시에 렌더링하지 않습니다. 발전 출력·수요·유량은 시연용 예시 값이며 실제 설비 사양이 아닙니다. 수도는 연결 경로 판정이며 실제 유량 해석은 지원하지 않습니다.
