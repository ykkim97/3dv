# Electric Smart Grid · 리버 에너지 시티

`Electric_Smart_Grid.city.json`을 앱 상단의 도시 파일 열기로 불러오세요.
중형 480 × 480 m 맵이며, TEST_2의 기존 건물·강변·교량을 바탕으로 외곽을 확장했습니다.
원자력 발전소와 스마트 팩토리 프리셋이 추가된 현재 프로젝트에서 열어야 합니다.

## 데모 구성

- 남서쪽: 원자력 발전소, 원자로 격납건물, 냉각탑, 변전소와 ESS.
- 북서쪽: 풍력 단지와 규칙적으로 정렬한 태양광 패널.
- 남쪽: 태양광 마이크로그리드와 동쪽 송전 회랑.
- 북동쪽: ESS 집합 저장시설, 변전소, 관제 오피스.
- 동쪽: 스마트 팩토리 6곳, 주거 단지와 지역 배전시설.
- 중앙: 참고 파일의 주거·업무·공공시설과 수변 녹지.
- 추가 대교, 연결 도로, 가로등과 캠퍼스 녹지.

시점·이미지 저장 메뉴에 전체 전경, 원자력, 재생에너지, ESS, 공장, 도심의
카메라 즐겨찾기 6개가 들어 있습니다. 오후 4시로 시작하며 조명 메뉴에서
야간으로 바꾸면 기존 창문·가로등·교량 조명을 볼 수 있습니다.

정보 보기의 전력 레이어를 켜면 공급 범위와 연결 상태를 확인할 수 있습니다.
전력 공급 판정은 기존 에디터의 거리 기반 모델입니다. 아래 흐름선은 별도의
개념적 연결망이며, 전력 용량·조류·수요 반응·원전 운전·에너지 거래를 계산하지 않습니다.
옥상 태양광은 공장 프리셋의 외형 장식이며 별도의 발전원으로 계산하지 않습니다.
태양열 대신 현재 제공되는 태양광 프리셋을 사용했습니다.

## 전력 흐름 연결선

현재 도시 파일에는 전력 연결선 208개가 저장되어 있습니다. 기본 표시 192개,
ESS 방전 대안 16개는 숨김 상태입니다. 기존 시설·도로·부지·지형·카메라는 유지했습니다.

| 색상 | 연결 단계 | 연결선 수 |
| --- | --- | --- |
| 노랑 | 원자력·기존 발전소·태양광·풍력 → 가까운 집전 변전소 | 30 |
| 주황 | 변전소와 송전탑을 연결한 주 송전망 | 35 |
| 하늘색 | 변전소 → 지역 배전 피더 → 배전시설 | 28 |
| 초록 | 배전시설 → 주거·업무·공공시설·공장 수요처 | 83 |
| 파랑 | 변전·배전 버스 → ESS 충전 | 16 |
| 보라 | ESS → 변전·배전 버스 방전 (기본 숨김) | 16 |

주 송전망은 원자력 발전소의 변전소를 기준으로 방향을 표시합니다. 재생에너지는
각 지역 변전소에 전력을 주입하는 개념입니다. 지역 배전은 짧은 분기망으로 연결했고,
모든 수요처에 주 발전원에서 도달 가능한 연결 경로가 있는지 검사했습니다.
선의 굵기·속도는 단계 구분을 위한 연출이며 실제 전압이나 전력량을 뜻하지 않습니다.

상단 **흐름 연결**에서 연결선을 선택해 색상·방향·속도·표시 상태를 바꿀 수 있습니다.
**흐름 효과**에서 이동 띠·방향 화살표·빛 펄스·점 흐름·에너지 파동을 선택할 수 있습니다.
데모는 발전에 펄스, 송전에 화살표, 배전에 이동 띠, 수요처에 점 흐름,
ESS 충전에 에너지 파동을 적용했습니다.
방전 시나리오를 보려면 파랑 ESS 충전선을 숨기고, 반대 방향의 보라 방전선을 표시하세요.
충전선과 방전선은 서로 다른 경로·높이를 사용합니다. 화면의 공급 범위와는 독립적인
시각화이므로 공급 판정 결과는 이 설정으로 바뀌지 않습니다.

## 검증 및 성능

`validation.json`에 시설 수, 신규 배치, 도로 접근 및 전력 공급 결과가 있습니다.
`power-network-validation.json`에 연결선 단계별 수와 도달성 검증 결과가 있습니다.
`city-layout.svg`는 배치를 설명하는 평면도입니다.
도로·부지·신규 시설의 배치 규칙과 전체 JSON 형식을 검증했습니다.
가로등은 기존 인스턴스 렌더링을 사용하고, 신규 프리셋은 공유 재질과 적은
폴리곤을 사용합니다. 실제 프레임 속도는 GPU와 화면 해상도에 따라 달라집니다.

최적화 후 연결선 192개는 메시 6개와 공유 재질 1개로 렌더링합니다.
반복 시설과 차량은 인스턴스를 공유하고, 정적인 가로등은 재질별로 병합합니다.
그림자는 시설·도로·지형이나 햇빛이 바뀔 때 갱신합니다.
`performance-before.json`과 `performance-after.json`은 같은 데모의 시설·연결선·교통·
가로등을 비교한 NullEngine 구조 수치입니다. 기하 그룹은 2,662 → 232개,
재질은 269 → 78개입니다. 지형·도로·물·오버레이는 이 비교에 포함되지 않으며,
이 감소율을 실제 FPS 향상률로 해석하면 안 됩니다.

```sh
node scripts/benchmark-city-rendering.mjs
```
